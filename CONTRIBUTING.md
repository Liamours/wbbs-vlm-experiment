# Contributing and annotation corrections

Do not submit patient images or source data through issues or pull requests.

For a reproducibility or annotation concern, include the release version, `task_id` or `evidence_id`, a concise description, and the relevant provenance field. Report proposed clinical corrections as a review request; source labels are never silently replaced.

Changes to source adapters, release policies, task templates, or split logic require a new release version and regenerated inventory, validation, and split reports.
